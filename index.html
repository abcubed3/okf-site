Turn schemas and docs into verified context for AI agents.

Keep your tables, APIs, metrics, and runbooks in plain, Git-native Markdown. Harvest existing metadata, validate links and freshness, and serve exact context via MCP or SKILL.md—no vector DB required.

Quickstart

Adopt in 3 commands

Start right now in any Git repository—or point OKF at an existing database or OpenAPI spec.

1

Harvest or author

Bootstrap linked Markdown concepts from any repo, schema, or spec.

okf harvest git --output ./knowledge

Or harvest db (Postgres, MySQL, BigQuery, Spanner), openapi, proto & web.

2

Validate links & trust

Catch broken links, missing metadata, and stale concepts.

okf lint ./knowledge

Checks OKF v0.3 schemas, provenance, and relative Markdown links.

3

Give it to AI agents

Install the workspace skill and start the local MCP server.

okf skill install && okf mcp --bundle ./knowledge

Works out of the box with Claude Code, Cursor, and Antigravity.

How OKF Works

Plain Markdown in Git. Exact context for agents.

No proprietary datastore. An OKF bundle is a folder of Markdown files connected by normal links—so humans review PRs in Git while agents traverse exact relationships.

knowledge/tables/orders.md Git-Native .md 
---
type: "Table"
title: "Orders"
description: "Customer checkout orders and line-item totals."
resource: "public.orders"
stale_after: "2027-01-01T00:00:00Z"
verified:
  - by: "human:data-team@acme.dev"
    at: "2026-08-01T12:00:00Z"
---

# Orders Table

Stores completed customer transactions.
Foreign key `user_id` joins to [Users](users.md).
Operational retention follows [DB Cleanup](../playbooks/database_cleanup.md).
Deterministic BFS Context Assembly
Click "Animate Traversal" to trace links within a token budget.
Seed: tables/orders
Hop 1: tables/users & playbooks/db_cleanup
Hop 2: apis/create_user & tables/transactions

Auto-Harvest Sources

Bootstrap from Postgres, MySQL, BigQuery, Spanner, OpenAPI, Protobuf, Git, or web docs. Add --ai-enrich to draft descriptions.

Trust & Governance (v0.3)

Track provenance (sources), human or CI verification (verified), freshness (stale_after), and certified SQL (Attested Computation).

MCP & Agent Skills

Serve live search, bounded context assembly, and grounded Q&A over MCP—or compile your bundle into a portable SKILL.md.

Fast Go Tooling

Parses ~97k concepts/sec in a single binary. Includes static HTML graph docs (okf doc), IDE diagnostics (okf lsp), and JSON-LD export.
